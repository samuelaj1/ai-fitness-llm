# AI Smart Fitness LLM

An AI-powered fitness support platform that helps users build sustainable fitness habits using **Large Language Models (LLMs)** and the **COM-B behavioral change framework**.

The system provides personalized coaching, mood-aware support, goal tracking, and motivational guidance to help users stay consistent with their fitness journey.

## Features

- 🤖 AI fitness coach with conversational support
- 🎯 SMART goal tracking
- 😊 Mood & emotional check-ins
- 📊 Fitness progress analytics
- 🔔 Reminders and motivational nudges
- 🧠 COM-B behavior-based coaching
- 🍎 Nutrition and wellness support

## Installation

Clone the project:

```bash
git clone https://github.com/yourusername/ai-smart-fitness-llm.git
```

Go into the project:

```bash
cd ai-smart-fitness-llm
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=
MONGODB_URI=
JWT_SECRET=
```
